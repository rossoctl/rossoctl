## Learn by running something

- **[Demos](demos.md)** — end-to-end scenarios you can reproduce.
- **[rossoctl/examples](https://github.com/rossoctl/examples)** — sample agents in several frameworks,
  and MCP tools under [`mcp/`](https://github.com/rossoctl/examples/tree/main/mcp).
- **[capture-the-flag](https://github.com/rossoctl/capture-the-flag)** — scenarios that demonstrate and
  test the platform's security posture. The most direct way to see what the guarantees actually stop.

## Repositories

The platform spans several repositories. The ones you are most likely to need:

| Repository | What it is |
| --- | --- |
| [rossoctl](https://github.com/rossoctl/rossoctl) | Installer, console, backend, and these docs |
| [operator](https://github.com/rossoctl/operator) | The Kubernetes operator and the CRDs |
| [cortex](https://github.com/rossoctl/cortex) | The data plane, its plugins, and its demos |
| [rossoctl-cli](https://github.com/rossoctl/rossoctl-cli) | The CLI |
| [examples](https://github.com/rossoctl/examples) | Sample agents and tools |
| [context-service](https://github.com/rossoctl/context-service) | Agent context provisioning |
| [context-guru](https://github.com/rossoctl/context-guru) | The context compaction engine |
| [workload-harness](https://github.com/rossoctl/workload-harness) | Load generation and benchmarking |
| [mcp-gateway](https://github.com/Kuadrant/mcp-gateway) | The MCP Gateway, hosted under Kuadrant |

The full list is on the [organisation profile](https://github.com/rossoctl).

## Get help

- **[Slack](https://ibm.biz/rossoctl-slack)** — the fastest route to an answer.
- **[Issues](https://github.com/rossoctl/rossoctl/issues)** — bugs and feature requests.
- **Email** — `rossoctl-maintainers@googlegroups.com` reaches the maintainer team.
